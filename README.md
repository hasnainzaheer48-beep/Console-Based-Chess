# Console-Based Chess Game (C++)

Built a feature-rich console-based Chess game from scratch in C++ using object-oriented programming principles, without relying on external game engines or libraries. The project accurately implements the official rules of chess while maintaining a modular and scalable codebase through well-structured classes for the board, pieces, players, and game management.

### Features

* Complete implementation of standard chess rules
* Legal move validation for all pieces
* Check, checkmate, and stalemate detection
* Castling (both kingside and queenside)
* En passant captures
* Pawn promotion
* Piece capturing mechanics
* Turn-based gameplay
* Move history tracking
* Console-based board rendering
* Robust input validation and game state management
* Modular object-oriented architecture for maintainability and future expansion

### Technologies

* C++
* Object-Oriented Programming (OOP)
* Standard Template Library (STL)
* Visual Studio

This project strengthened my understanding of algorithms, game state management, object-oriented design, debugging, and software architecture by recreating one of the world's most rule-intensive board games entirely from scratch.
